# Wonder Weather

A simple and clean weather application that fetches real-time weather data using a public weather API.  
Built with HTML, CSS, and JavaScript.

## 🌦 Features
- Search weather by city
- Real-time temperature, humidity, and conditions
- Clean UI with basic styling
- Responsive layout 

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
- Weather API 

## 🚀 How to Run
1. Clone the repository:
git clone https://github.com/m9hr7fcmyt-wq/Wonder-Weather.git (github.com in Bing)

2. Open `index.html` in your browser.
