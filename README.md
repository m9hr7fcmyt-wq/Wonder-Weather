
# Wonder Weather

A simple and clean weather application that fetches real-time weather data using a public weather API.  
Built with HTML, CSS, and JavaScript.

## 🌦 Features
- Search weather by city
- Real-time temperature, humidity, and conditions
- Clean UI with basic styling
- Responsive layout 

### 🛠 Tech Stack
- **HTML5**
- **CSS3** (glassmorphism, responsive design)
- **JavaScript (ES6+)**
- **Fetch API**
- **Weather API**
- **LottieFiles animations**
- **MP4 background videos**
- **JSON data handling**
- **Git & GitHub**

## ✨ Features
- Search weather by city
- Real‑time temperature, humidity, and conditions
- Dynamic background videos (rain, snow, clear, clouds, mist)
- Lottie animated weather icons
- Autocomplete city search
- Clean glassmorphism UI
- Responsive layout for desktop and mobile

## 🚀 Getting Started
-Open WeatherApi.html in your browser
-Search any city to see real‑time weather and dynamic visuals

## 🧠 How It Works
- Fetches weather data from a public API
- Parses conditions and selects the correct background video
- Displays animated icons using LottieFiles
- Updates UI instantly when a new city is searched
- Autocomplete suggestions appear as you type
